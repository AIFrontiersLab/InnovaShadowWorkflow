## Why this exists

Most valuable internal processes live in copy-paste across five tabs.

**Why now:** Computer-use traces can be collected with consent.

**What recently changed:** Multimodal GUI agents.

**Why it was hard before:** Screen understanding was too weak.

## MVP

Record a consented week of a role, cluster repeated jobs, propose one automatable slice.

### Core loop

1. Accept an agent (or human-on-behalf-of-agent) intent
2. Enforce scope / policy / evidence
3. Execute the smallest useful autonomous step
4. Leave an audit trail a human can kill-switch
